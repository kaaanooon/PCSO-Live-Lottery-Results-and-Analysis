## Phone screenshots

Capture real app screens at 1080 x 1920 or another 9:16 resolution. Recommended set:

1. Results — latest game cards, jackpots, and winners.
2. Game history — previous draws for one game.
3. Pick — saved combinations and the add-pick action.
4. Analysis — latest-10-draw findings and random combination.

Use actual app captures rather than generated UI. Do not include personal notifications, test-ad labels, debug menus, or device identifiers.
